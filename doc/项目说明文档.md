# LabelImg 项目说明文档

> 版本：1.8.6 ｜ 许可：MIT ｜ 语言：Python（PyQt5 / PyQt4）

---

## 一、项目简介

**LabelImg** 是一款开源的**图形化图像标注（Image Annotation）工具**，用于为目标检测任务绘制矩形标注框（bounding box）。它使用 Python 编写，界面基于 Qt（PyQt5 / PyQt4）。

标注结果默认保存为 **PASCAL VOC** 格式的 XML 文件（即 ImageNet 所使用的格式），同时也支持 **YOLO**（txt）与 **CreateML**（json）格式。

> 注：LabelImg 由 Tzutalin 创建，目前已并入 Label Studio 社区，不再积极开发。本仓库为其经典版本源码。

主要用途：

- 为图像中的目标物体绘制矩形框并打上类别标签。
- 生成可用于训练目标检测模型（Faster R-CNN、YOLO 等）的标注文件。

## 二、功能特性

| 功能 | 说明 |
| --- | --- |
| 多种标注格式 | PASCAL VOC（`.xml`）、YOLO（`.txt`）、CreateML（`.json`），可一键切换 |
| 快捷标注 | `w` 创建框、`a`/`d` 切换图片、`Ctrl+S` 保存等丰富快捷键 |
| 目录批量处理 | `Ctrl+u` 打开整个目录，自动扫描并排序全部图片 |
| 预定义类别 | 从 `data/predefined_classes.txt` 载入候选类别（默认已清空），支持下拉补全 |
| 自动保存模式 | 切换到下一张图片时自动保存当前标注 |
| 单类别模式 | 连续标注同一类别，提升批量标注效率 |
| 困难标记（difficult） | 标记难以识别的目标，训练时可选择性忽略 |
| 图片校验（verified） | 空格键将图片标记为「已校验」，画布显示绿色背景 |
| 删除/移动图片 | 标注过程中删除不需要的图片，或移动到其它目录；其标注文件同步处理，文件列表自动更新并跳到原来顺序的下一张 |
| 尺寸显示 | 状态栏常驻显示当前图片尺寸（`Image: 宽 x 高`）与当前选中框的尺寸（`Box: 宽 x 高`），框被移动或缩放时实时刷新 |
| 绘制正方形 | `Ctrl+Shift+R` 或按住 `Ctrl` 强制绘制正方形框 |
| 缩放与亮度 | 滚轮缩放、亮度调节（`Ctrl` / `Ctrl+Shift` + 滚轮） |
| 颜色自定义 | 按标签文本哈希自动配色，也可手动指定边框/填充色 |
| 多语言界面 | 支持简体中文、繁体中文、日文（资源包机制） |
| 最近文件 | 文件菜单记录最近打开的 7 个文件 |

## 三、技术栈

- **语言**：Python（`setup.py` 要求 `>=3.0.0`；代码同时兼容 Python 2 + Qt4）
- **GUI 框架**：PyQt5（推荐）/ PyQt4
- **XML 处理**：`lxml`（`pascal_voc_io.py` 用于格式化输出）
- **资源编译**：`pyrcc5 resources.qrc -o libs/resources.py`
- **打包**：`pyinstaller`（Windows EXE）、`py2app`（macOS）、PyPI
- **测试**：Python `unittest`（`tests/`，通过 `make test` 运行）

依赖清单（`requirements/requirements-linux-python3.txt`）：

```
pyqt5==5.14.1
lxml==4.9.1
```

## 五、架构设计

### 5.1 整体架构

程序采用经典的 **Qt MVC 风格 + 信号槽机制**：

```
                    ┌───────────────────────────────┐
                    │      labelImg.py               │
                    │      MainWindow                │
                    │  （菜单/工具栏/状态栏/事件编排）│
                    └───────────────┬───────────────┘
                                    │ 信号 / 槽
              ┌─────────────────────┼─────────────────────┐
              ▼                     ▼                     ▼
      ┌──────────────┐      ┌──────────────┐      ┌──────────────┐
      │  Canvas      │      │  LabelFile   │      │  Settings    │
      │（画布渲染与  │      │（标注读写    │      │（配置持久化）│
      │  鼠标交互）  │      │  调度中心）  │      └──────────────┘
      └──────┬───────┘      └──────┬───────┘
             │                     │
             ▼                     ▼
      ┌──────────────┐   ┌───────────────────────────────────┐
      │   Shape      │   │ PascalVocIO │ YoloIO │ CreateMLIO │
      │（框的数据    │   └───────────────────────────────────┘
      │  与绘制）    │
      └──────────────┘
```

- **`MainWindow`** 负责所有 UI 编排、状态管理（`dirty`、当前文件、图片列表、缩放/亮度等），并通过信号槽与 `Canvas` 通信。
- **`Canvas`** 专注于图像与标注框的**渲染和鼠标交互**，通过信号（`newShape`、`shapeMoved`、`selectionChanged`、`zoomRequest` 等）通知主窗口。
- **`LabelFile`** 是标注读写的**统一入口**，根据当前 `LabelFileFormat` 分派给对应格式的 Writer。
- **`Shape`** 封装单个标注框的数据（点集、标签、颜色、difficult）及自绘逻辑。

### 5.2 数据流（标注一张图片）

```
打开目录/文件
  → MainWindow.import_dir_images() / load_file()
  → Canvas.load_pixmap() 显示图片
  → show_bounding_box_from_annotation_file() 读取已有标注
  → 用户绘制：Canvas.handle_drawing() → finalise() → 发 newShape 信号
  → MainWindow.new_shape() 弹出 LabelDialog 输入标签
  → MainWindow.add_label() 将 Shape 与列表项双向关联
  → 保存：MainWindow.save_file() → save_labels()
       → LabelFile.save_pascal_voc_format() / save_yolo_format() / save_create_ml_format()
```

### 5.3 关键数据结构

- `canvas.shapes`：当前图片的所有 `Shape` 对象列表。
- `MainWindow.items_to_shapes`：`QListWidgetItem → Shape` 映射。
- `MainWindow.shapes_to_items`：`Shape → QListWidgetItem` 映射。
- `LabelFile.suffix`：当前格式的扩展名（`.xml` / `.txt` / `.json`），由 `MainWindow.set_format()` 切换。

## 六、标注格式说明

### 6.1 PASCAL VOC（`.xml`）

```xml
<annotation verified="yes">
  <folder>images</folder>
  <filename>demo.jpg</filename>
  <path>...</path>
  <source><database>Unknown</database></source>
  <size>
    <width>800</width><height>600</height><depth>3</depth>
  </size>
  <segmented>0</segmented>
  <object>
    <name>person</name>
    <pose>Unspecified</pose>
    <truncated>0</truncated>
    <difficult>0</difficult>
    <bndbox>
      <xmin>60</xmin><ymin>40</ymin>
      <xmax>430</xmax><ymax>504</ymax>
    </bndbox>
  </object>
</annotation>
```

实现：`libs/pascal_voc_io.py`。`difficult` 会保留；当框触及图片边界时 `truncated` 自动置 1。

### 6.2 YOLO（`.txt`）

每行一个目标，格式为归一化后的：

```
<class_index> <x_center> <y_center> <width> <height>
```

- 坐标为相对图片宽高的归一化值（0~1）。
- 类别索引对应同目录下自动生成的 `classes.txt`。
- **注意**：YOLO 格式会**丢弃 difficult 标记**，且 `classes.txt` 在保存时会被覆盖更新（历史标注不会同步更新，因此中途不要更改类别列表）。

实现：`libs/yolo_io.py`。

### 6.3 CreateML（`.json`）

```json
[
  {
    "image": "demo.jpg",
    "verified": true,
    "annotations": [
      {
        "label": "person",
        "coordinates": { "x": 297.5, "y": 307.5, "width": 105, "height": 115 }
      }
    ]
  }
]
```

坐标以**矩形中心点** `x, y` 加 `width, height` 表示。实现：`libs/create_ml_io.py`。

> 三种格式的读写均由 `libs/labelFile.py` 统一封装调用。

## 八、使用说明与快捷键

### 8.1 基本流程（PascalVOC）

1. 启动程序。
2. 菜单 `File → Change default saved annotation folder` 设置标注保存目录。
3. 点击 `Open Dir` 打开图片所在目录。
4. 点击 `Create RectBox`（或按 `w`）。
5. 按住鼠标左键拖拽绘制矩形框，松开后输入类别。
6. 用右键拖动可复制/移动框。

### 8.2 YOLO 流程

1. 在 `data/predefined_classes.txt` 中定义类别列表。
2. 启动程序，点击工具栏中的格式按钮切换到 `YOLO`。
3. 使用 Open / OpenDir 处理图片，完成后点击保存。标注 txt 与 `classes.txt` 会保存到图片同目录。

### 8.3 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + u` | 打开目录（载入全部图片） |
| `Ctrl + r` | 更改标注保存目录 |
| `Ctrl + s` | 保存 |
| `Ctrl + Shift + S` | 另存为 / 单类别模式 |
| `Ctrl + d` | 复制当前框与标签 |
| `Ctrl + Shift + d` | 删除当前图片（会一并删除其标注文件） |
| `Ctrl + Shift + m` | 将当前图像移动到其它目录（标注文件一并移动） |
| `Ctrl + v` | 复制上一张图片的标注框 |
| `Space` | 标记当前图片为已校验 |
| `w` | 创建矩形框 |
| `d` | 下一张图片 |
| `a` | 上一张图片 |
| `Del` | 删除选中的框 |
| `Ctrl + +` / `Ctrl + -` | 放大 / 缩小 |
| `Ctrl + =` | 原始尺寸 |
| `Ctrl + F` / `Ctrl + Shift + F` | 适应窗口 / 适应宽度 |
| `Ctrl + Shift + R` | 切换正方形绘制 |
| `↑ → ↓ ←` | 移动选中的框 |

### 8.4 概念说明

- **Verify Image**：按空格将图片标记为已校验，画布变绿，适用于自动生成数据集后的快速复核。
- **Difficult**：标记「难以识别」的目标。是否在训练中纳入由具体网络实现决定。
- **单类别模式**：连续创建同一类别的框，加快批量标注。

## 九、配置与设置

- 配置文件：`~/.labelImgSettings.pkl`（使用 `pickle` 序列化）。
- 保存内容：窗口大小/位置/状态、最近文件、线框色/填充色、保存目录、自动保存、单类别模式、显示标签、绘制正方形、当前标注格式等。
- **会话记忆**：退出时会记住最后打开的图片目录（`lastOpenDir`）与标注保存目录（`savedir`）。下次启动若未通过命令行指定路径，会自动重新打开上次的图片目录，并保留上次的保存目录（不会被图片目录覆盖）。
- **可移植性与容错**：配置只保存基础类型（`window/state` 存 `bytes`，颜色/尺寸/坐标存列表，标注格式存整数），因此不受 PyQt/sip/Python 版本差异影响；若文件无法解析，会打印具体失败原因，并把原文件改名为 `~/.labelImgSettings.pkl.pkl.bak` 保留，而不是被下一次保存静默覆盖。
- 重置方式：
  1. 菜单 `File → Reset All`（会删除配置并重启程序）；
  2. 手动删除 `~/.labelImgSettings.pkl`。

相关常量定义见 `libs/constants.py`，读写逻辑见 `libs/settings.py`。

## 十、开发者指南

### 10.1 扩展一种新的标注格式

1. 在 `libs/` 下新建 `xxx_io.py`，实现 `XxxWriter` 与 `XxxReader`（参考 `yolo_io.py`）。
   - Reader 的 `get_shapes()` 需返回形如
     `[(label, [(x1,y1),(x2,y2),(x3,y3),(x4,y4)], line_color, fill_color, difficult), ...]` 的列表。
2. 在 `libs/labelFile.py` 中：
   - 在 `LabelFileFormat` 枚举中新增成员；
   - 新增 `save_xxx_format()` 方法；
   - 在 `MainWindow.save_labels()` 中增加分派分支。
3. 在 `labelImg.py` 中：
   - 在 `set_format()` / `change_format()` / `get_format_meta()` 中加入新格式；
   - 在 `show_bounding_box_from_annotation_file()`、`load_xxx_by_filename()` 中支持读取。
4. 在 `libs/constants.py` 增加格式名常量与配置键。

### 10.2 多语言

界面字符串位于 `resources/strings/`：

- `strings.properties`（英文，默认）
- `strings-zh-CN.properties`（简体中文）
- `strings-zh-TW.properties`（繁体中文）
- `strings-ja-JP.properties`（日文）

修改后需重新执行 `pyrcc5 -o libs/resources.py resources.qrc` 生成资源文件。加载逻辑见 `libs/stringBundle.py`（按系统区域自动回退）。

### 10.3 关键注意点

- `libs/resources.py` **不在版本库中**，首次运行前必须由 `pyrcc5` 生成，否则 `from libs.resources import *` 会失败。
- 代码同时保留 PyQt4 兼容分支（`try/except ImportError`），改动时注意不要破坏兼容性。
- `MainWindow` 中 `self.dirty` 标记「有未保存修改」，切换/关闭时通过 `may_continue()` 提示。

## 十二、附加工具

`tools/label_to_csv.py`：将 YOLO（`.txt`）或 PASCAL VOC（`.xml`）标注转换为 **Google Cloud AutoML** 所需的 CSV 格式。

```shell
python label_to_csv.py -h
python label_to_csv.py -p <bucket> -l <labels_dir> -m txt [-o res.csv] [-c classes_path]
```

| 参数 | 说明 |
| --- | --- |
| `-p/--prefix` | 云端存储桶路径前缀（生成 `gs://...` 路径） |
| `-l/--location` | 标注文件父目录（内含 TRAINING / VALIDATION / TEST / UNASSIGNED） |
| `-m/--mode` | `xml` 或 `txt` |
| `-o/--output` | 输出 CSV 文件名，默认 `res.csv` |
| `-c/--classes` | 类别文件路径，默认 `data/predefined_classes.txt` |

目录组织要求详见 `tools/README.md`。
